# HarmonyOS-MusicPlayer 🎵

本项目是一款基于 HarmonyOS NEXT 开发的沉浸式音乐播放器。

## ✨ 核心功能亮点

### 1. 智能歌词系统
* **异步解析**：支持标准 .lrc 文件解析，精准匹配分、秒、毫秒。
* **实时同步**：歌词随音乐进度平稳滚动，当前行高亮并具备缩放动效。

### 2. 沉浸式视觉交互
* **黑胶模式**：经典的黑胶唱片旋转动效，支持自定义唱片封面。
* **歌词模式**：全屏歌词浏览，配合动态背景模糊与颜色渐变。
* **场景化 UI**：不同模式下背景自动切换氛围（色调、模糊度动态调整）。
* **极简美学重构 (New)**：全面去除原本高饱和度的翠绿色，进度条、播放盘、高亮歌词全线洗白，视觉向北欧极简风靠拢，并引入全屏 30% 磨砂玻璃一体化悬浮控制台。

### 3. 系统能力与全场景横竖屏适配 (New)
* **AVPlayer 状态机**：严谨处理音频加载、准备、播放及进度更新逻辑。
* **“一多”多端自适应**：引入原生栅格系统（GridRow/GridCol）与断点监听。平板及大屏端自动分栏，左右并排常驻显示。
* **动态宽高比感知 (New)**：集成 `onAreaChange` 实时视口宽高比检测。在手机横屏、折叠屏展开等复杂场景下，应用能智能捕捉横屏状态并自动“变阵”为左右分栏布局，完美解决移动端横屏组件挤压溃散的行业痛点。
* **零占位音量气泡**：控制栏音量条重构为组件级 `bindPopup` 属性弹窗，点击喇叭向上弹出半透明微晶调节面板，释放纵向视觉空间。

---

## 🛠️ 技术栈

* **语言**：ArkTS (TypeScript based)
* **框架**：ArkUI (声明式 UI)
* **系统版本**：HarmonyOS NEXT (API 12+)
* **开发工具**：DevEco Studio 5.0.3+

增加黑胶唱片旋转动画。

优化进度条 (Slider) 与播放状态同步。

v1.2.0 (全能旗舰版)
新增：黑胶模式与歌词模式的平滑转场交互。

新增：调用系统相册自定义封面功能。

优化：全套 UI 升级为磨砂玻璃质感。

修复：解决特定版本下 .shadow 属性的兼容性报错。

v1.3.0 (极简美学多端自适应版 - 当前版本)
新增（横竖屏抗大乱斗）：加入底层 onAreaChange 监听，实时捕捉宽高比。当手机横屏或屏幕高宽突变时，应用自动启动响应式缩放，将原本挤压的上下堆叠瞬间平滑切换为左右 2:2 分栏，并将黑胶盘缩比例降至 50% 防撑爆，实现横竖屏完美通杀。

新增：隐藏式音量气泡面板（Popup）。干掉常驻的长音量条，改由 bindPopup 硬件加速弹窗托管，点击弹出，空白处自动隐退。

优化：全面“去绿留白”视觉重构。干掉翠绿色，将进度条、音量轨、播放中间按钮及高亮歌词更换为高奢纯白（#FFFFFF）与半透明灰白，质感大幅拉满。

优化：控制面板完全隐形。移除生硬的底色块，引入 backdropBlur(30) 顶级毛玻璃流光效果，让全屏背景自然透上来。
