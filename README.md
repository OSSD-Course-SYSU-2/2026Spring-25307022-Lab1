# HarmonyOS-MusicPlayer 🎵

本项目是一款基于 **HarmonyOS NEXT** 开发的沉浸式音乐播放器。
## ✨ 核心功能亮点

### 1. 智能歌词系统
- **异步解析**：支持标准 `.lrc` 文件解析，精准匹配分、秒、毫秒。
- **实时同步**：歌词随音乐进度平稳滚动，当前行高亮并具备缩放动效。

### 2. 沉浸式视觉交互
- **黑胶模式**：经典的黑胶唱片旋转动效，支持自定义唱片封面。
- **歌词模式**：全屏歌词浏览，配合动态背景模糊与颜色渐变。
- **场景化 UI**：不同模式下背景自动切换氛围（色调、模糊度动态调整）。

### 3. 系统能力集成
- **AVPlayer 状态机**：严谨处理音频加载、准备、播放及进度更新逻辑。

## 🛠️ 技术栈
- **语言**：ArkTS (TypeScript based)
- **框架**：ArkUI (声明式 UI)
- **系统版本**：HarmonyOS NEXT (API 12+)
- **开发工具**：DevEco Studio 5.0.3+
